Start in one command

Install the same skill
into five agent hosts.

The portable core follows the open Agent Skills SKILL.md format. Host-specific automation is an adapter, not a fork of your memory.

terminal
npx skills add stancsz/second-brain \
  --skill second-brain --global --copy -y \
  --agent claude-code codex gemini-cli opencode cline

Prefer no Node tooling? Clone the repository into your host's documented skills directory. The CLI itself only needs Python and SQLite.

After copying, run python scripts/brain_doctor.py --json for a read-only, content-free package, MCP, and pairing report. Run python scripts/host_matrix.py --json for the five-host package/MCP readiness matrix; native host activation remains a manual gate.

Compatibility without hand-waving

One standard core.
Honest host differences.

Native skill loading and the MCP protocol are portable. Automatic transcript capture and prompt-time recall currently use Claude Code hooks. Other hosts can use the skill and MCP server while their automation adapters mature.

Architecture

The database is a cache.
The files are the product.

This inversion is the moat. Every derived index and future cloud projection must be disposable. Recovery starts from the Bundle, not from a vendor API.

What works today

Portable interfaces

An Agent Skills package, a dependency-free CLI, and a standalone stdio MCP server over the same brain.

C

Readable Markdown

OKF frontmatter, wikilinks, recursive vault import, and tested manual-relation rebuild. Native Obsidian sync is not claimed.

Psychological structure

Subjects, affect, temporal validity, and supersession—stored in files instead of a proprietary person model.
