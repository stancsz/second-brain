A

把项目记下来

全文搜索、标签、集合、类型化链接、遍历、软删除和按时间回忆，都在本地完成。

B

从任意主机接入

一份 Agent Skills 包、一个无依赖 CLI，再加一个服务同一份脑子的 stdio MCP server。

C

把 Markdown 带走

OKF frontmatter、wikilink、递归 vault 导入和手工关系重建。原生 Obsidian 实时同步目前不做承诺。

D

记住关系与变化

主体、情绪、时间有效性和替代关系都能写进文件，不会被压成一条没来由的摘要。
