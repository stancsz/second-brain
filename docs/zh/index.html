一条命令，开始长脑子

同一份 Skill
装进五种 Agent。

核心遵循开放的 Agent Skills SKILL.md 格式。主机适配是插头，不是记忆的分叉。

terminal
npx skills add stancsz/second-brain \
  --skill second-brain --global --copy -y \
  --agent claude-code codex gemini-cli opencode cline

不想用 Node？把仓库复制到主机文档指定的 skills 目录。CLI 本身只需要 Python 和 SQLite。

复制后运行 python scripts/brain_doctor.py --json，做一次只读、不暴露内容的安装与配对检查。

五种诚实的差异。

Agent Skills 和 MCP 协议可以跨主机。自动捕获与 prompt-time recall 目前主要由 Claude Code hooks 提供；其他主机可以先用 Skill 和 MCP。

本地知识图谱

全文搜索、标签、集合、类型化链接、遍历、软删除和时间点回忆。

可携带的接口

Agent Skills 包、无依赖 CLI，以及对同一份脑子的 stdio MCP server。

C

看得懂的 Markdown

OKF frontmatter、wikilink、递归 vault 导入和手工关系重建。暂不声称原生 Obsidian 实时同步。

D
